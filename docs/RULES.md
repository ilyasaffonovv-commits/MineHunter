# Каталог правил MineHunter (генерируется из исходников)

Каждая улика — это правило с **идентификатором**, **категорией** и **весом**. Итоговый балл считается прозрачно (см. `RISK_MODEL.md`): улики одной категории ограничены потолком, повторяющиеся сигналы весят меньше, а вердикт «Высокий риск»/«Вредоносное» выдаётся только когда сходятся **независимые** категории. Отрицательный вес — «доверие» (подпись известного издателя и т.п.).

Правил в коде: **116**, правил командной строки в `rules/core.json`: **38**. Версия набора правил: `2026.09.26.1`.
