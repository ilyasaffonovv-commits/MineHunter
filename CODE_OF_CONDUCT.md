# Code of conduct

Be respectful and constructive. Criticise code and ideas, not people. No harassment, no discrimination, no personal attacks, no doxxing (including of malware victims).

Requests for help with attacking systems, evading detection for malicious purposes, or creating/distributing malware are off-topic and will be closed. Analysis of malware behaviour for the purpose of detection and cleaning is welcome.

Maintainers may edit, close or remove contributions that violate these rules and may block repeat offenders. Report concerns via a private message to the maintainer or through GitHub's report tools.
